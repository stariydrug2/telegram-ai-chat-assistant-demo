# TeleFlow Neurochatting Demo

Демо показывает сценарий настройки AI-помощника для Telegram: один аккаунт, два чата и один ответ-предпросмотр за запуск. Это локальный пример интерфейса и лимитов, он не подключается к Telegram и не отправляет сообщения.

**Полная версия:** [teleflow.space](https://teleflow.space/)

## Ограничения демо

- Один подключённый Telegram-аккаунт.
- Не более двух чатов.
- Ответ создаётся как черновик. Отправка сообщений и фоновая автоматизация в демо отключены.

Эти ограничения являются частью демонстрационного сценария. Они не заменяют доступность и поддержку полной версии TeleFlow.

## Возможности

- Демонстрация ограничения на один аккаунт и два чата.
- Одно поле для примера сообщения и один локальный предпросмотр.
- Переход на полный сервис для подключения Telegram и Gemini.

## Требования

- Python 3.12+
- Python 3.12+

## Запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   # Windows: .venv\\Scripts\\activate
   # macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Запустите локальный демонстрационный интерфейс:

   ```bash
   python app.py
   ```

Этот пример не запрашивает Telegram API ID, API Hash или ключ AI: в нём нет настоящей интеграции с аккаунтами или генерацией текста.

## Полная версия TeleFlow

В демо нет входа в Telegram, генерации AI, отправки ответов, мониторинга и полноценных кампаний. Полный нейрочатинг, другие инструменты, единая панель настройки и тарифы доступны на [teleflow.space](https://teleflow.space/).

## Ответственное использование

Используйте Telegram-аккаунт, которым владеете. Настраивайте ответы только в чатах, где автоматизация разрешена правилами сообщества. Не отправляйте нежелательные сообщения и не пытайтесь обходить ограничения Telegram. Сервисные сообщения модерации и запреты на публикацию должны приводить к остановке обработки чата.

Telegram может ограничить аккаунт за нежелательные сообщения. Никакие задержки или настройки не гарантируют отсутствие ограничений.
